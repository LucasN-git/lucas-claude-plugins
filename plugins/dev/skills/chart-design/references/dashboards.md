# Dashboards that get used

Dashboards go unused because numbers lack context and the page is organized for the people
who built it. Two rules and a check.

## Every number carries its context

Each KPI shows a benchmark (last period, same period last year, peers), a target with a
visible state (on track, ahead, danger) and, where it moved, a note on why. Annotations
explain; they never restate the value.

## Group by the user's workflow

KPIs the user came for first, drill-down below. Group by how the user thinks (campaign,
product line, region), never by data source. Same visual style on every page.

## Before publishing

1. Five-second test: what is happening, what is going well, what is concerning, without
   reading twice?
2. Every number is tied to a decision someone makes; a number nobody acts on goes.
3. Every number has its benchmark, history or explanation.
4. Hand the user this question: is the grouping how you think about it? Adjust to the answer.
5. Whatever serves none of the answers above is removed.
